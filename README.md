## 主要功能

| 分类 | 功能 |
| --- | --- |
| 内容浏览 | 推荐、热门、番剧、直播、动态、专栏与搜索筛选 |
| 视频播放 | 分 P / 合集播放、倍速与手势控制、画中画、硬件解码、记忆播放 |
| 弹幕字幕 | 直播弹幕、高级弹幕、弹幕合并、字幕大小与弹幕显示设置 |
| 社区互动 | 点赞、投币、收藏、评论、私信、发布动态与富文本编辑 |
| 个人管理 | 观看历史、稍后再看、收藏夹管理、关注分组、多账号 |
| 扩展功能 | 离线缓存、DLNA 投屏、WebDAV 备份、SponsorBlock、视频转动图、AI 原声翻译 |

<details>
<summary>查看更多功能</summary>

- **播放体验**：长按倍速、高能进度条、进度缩略图预览、音质与解码格式选择、全屏方向设置、跳过番剧片头片尾、音频播放。
- **视频与直播**：互动视频、课堂视频、视频 TAG、合集管理、直播分区、直播弹幕表情。
- **动态与评论**：图文动态、带图评论、楼中楼对话与定位、评论排序、评论点踩、评论与动态保存、投票及话题。
- **收藏与账号**：收藏夹创建、编辑、排序与批量管理，稍后再看管理，Cookie 登录，个人资料修改。
- **界面与设置**：亮色 / 暗色 / 跟随系统、横屏适配、无痕与游客模式、画质预设、亮度调节与振动反馈。

</details>

## 下载

前往 **[PiliPlus 上游 Releases](https://github.com/bggRGjQaUbCoE/PiliPlus/releases)** 获取各平台安装包。

本仓库源代码可通过 [GitHub](https://github.com/MXWF0/PiliPlus) 查看与下载。

## 本地构建

请先安装 Flutter SDK，并参考 [pubspec.yaml](pubspec.yaml) 中的 Flutter / Dart 版本要求。

```bash
git clone https://github.com/MXWF0/PiliPlus.git
cd PiliPlus
flutter pub get
flutter run
```
