## Features

| Category | Features |
| --- | --- |
| Browse | Recommendations, trending videos, anime, live streams, posts, articles, and search filters |
| Playback | Multi-part videos and playlists, playback speed and gestures, PiP, hardware decoding, resume playback |
| Danmaku & subtitles | Live danmaku, advanced danmaku, danmaku merging, subtitle sizing and display settings |
| Community | Likes, coins, favorites, comments, messages, posts, and rich-text editing |
| Library & accounts | Watch history, Watch Later, favorites, following groups, and multiple accounts |
| Extras | Offline playback, DLNA casting, WebDAV backup, SponsorBlock, video-to-GIF, and AI voice translation |

<details>
<summary>More features</summary>

- **Playback:** press-and-hold speed boost, highlight progress bar, thumbnail scrubbing, audio and codec selection, fullscreen orientation, intro/outro skipping, and audio playback.
- **Videos & live:** interactive videos, classroom videos, video tags, collection management, live categories, and live danmaku reactions.
- **Posts & comments:** image posts, image comments, nested comment conversations and navigation, sorting, downvotes, saving comments and posts, polls, and topics.
- **Favorites & accounts:** create, edit, sort, and batch-manage favorites; Watch Later management; cookie login; profile editing.
- **Appearance & settings:** light/dark/system themes, landscape layouts, incognito and guest modes, quality presets, brightness, and haptic feedback.

</details>

## Download

Get installation packages for supported platforms from **[upstream PiliPlus Releases](https://github.com/bggRGjQaUbCoE/PiliPlus/releases)**.

The source code for this repository is available on [GitHub](https://github.com/MXWF0/PiliPlus).

## Build from source

Install Flutter SDK and refer to [pubspec.yaml](pubspec.yaml) for the Flutter and Dart version requirements.

```bash
git clone https://github.com/MXWF0/PiliPlus.git
cd PiliPlus
flutter pub get
flutter run
```
